RobocorLead Software Engineer2024 to present

Robocor 2.0, the software on Robocor's security robots

Robocor builds security robots. I am the only software engineer there. I built Robocor 2.0, the software that runs the robots. The Guardian robot runs it at Nimnicht Chevrolet.

  • I wrote the whole stack, from the firmware link up to the operator app and the cloud.
  • The robot does its computer vision on board, so it can detect objects and judge distance without a cloud service.
  • Staff can talk to the robot through a voice agent I built on OpenAI.
  • I built corBench, a simulator that runs the real robot code before it goes on hardware. It has logged 580+ runs.

Stack Flutter, Python, NVIDIA Jetson, Supabase, Fly.io.

VEERA MedicalSoftware Developer III2021 to presentapp.recovr360.com

MedXR (Recovr360), physical therapy on Meta Quest

The patient wears a Quest headset and the practitioner runs the session from a browser. I built and launched it alone, and it is now in more than 15 clinics. I presented the platform live at ACRM 2023, where a clinician ran the demo.

  • I wrote the real-time backend, the WebXR client and the native Quest client.
  • I moved the platform from Fly.io to AWS and rolled out Auth0 login behind feature flags.
  • It works with the Xbox Adaptive Controller and wheelchair joysticks, so more patients can use it.
  • Before MedXR, I wrote the company's first application in C#, Unity and ASP.NET Core.

Stack TypeScript, Node, Colyseus, Svelte, Three.js, Unity, AWS.

Solla CodeMaintainer2026 to presentGitHubReleases

Solla Code, a fork of T3 Code for running several AI coding agents

I run several coding agents at once and the terminal was a bad way to do it. So I forked T3 Code and built on it. I have made 850+ commits since July 2026, and it ships nightly builds.

  • I added custom agents, scheduled tasks, side chats and an orchestrator.
  • I grew its MCP tools and the browser that agents and people share, so a person can take over a login mid-task.
  • This is how I work now. I direct coding agents day to day, and changes go through tests and CI before release.

Stack TypeScript, Electron, React, Node.js, Expo, MCP.
