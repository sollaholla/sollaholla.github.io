Robocor 2.0, the software on Robocor's security robots

Robocor builds autonomous security robots. I wrote Robocor 2.0, the software that runs them. One Flutter codebase for the operator app on iOS, Android, macOS, Windows, Linux and the web. Perception and navigation on NVIDIA Jetson. A cloud backend for fleets and telemetry. The Guardian robot patrols Nimnicht Chevrolet on this stack. I report to the founder and work with the hardware and firmware team. The operators at the dealership are the users.

  • Everything from the firmware serial protocol and motor watchdog to the cloud backend and operator UI is mine.
  • On-device perception with a ZED stereo camera. YOLO26 and YOLO-World for detection, plus metric depth and segmentation models. They run through ONNX Runtime, TFLite and TensorRT on Jetson. I maintain the Flutter ONNX Runtime plugin it uses.
  • GNSS/RTK path following, with mapping and navigation that keep working offline when the network drops.
  • An OpenAI GPT-4o operator agent with realtime voice, so staff can talk to the robot.
  • corBench, a WebGPU and Rapier physics test bench. Virtual sensor boards feed the real parsers, unchanged. 580+ recorded runs. The docking suite keeps eight saved scenarios as regression tests. Each one runs from 27 start poses. As of late October, 212 of 216 starts dock. The fast mode agrees with the rendered simulator within about 2 percent on distance and 1 degree on bearing.
  • Infrastructure: Supabase (Postgres, auth, storage), multi-tenant workers on Fly.io, Docker, CI, release pipelines for Windows, macOS and Jetson.

Stack Flutter and Dart, Python, NVIDIA Jetson, ONNX Runtime, TensorRT, YOLO26, YOLO-World, ZED stereo, GNSS/RTK, Supabase, Fly.io, OpenAI realtime, Rapier, WebGPU.

MedXR (Recovr360): physical therapy on Meta Quest, run by the practitioner from a browser

A white-label physical-therapy platform. The patient wears a Quest headset. The practitioner watches, adjusts and records from a browser. I built and launched it alone, backend to headset. The clinicians who use it shaped it. It is in more than 15 clinics. At ACRM 2023 a clinician ran a session on it wirelessly, on stage.

  • Node and TypeScript backend. Colyseus rooms hold the session state on the server, with a strict lifecycle. Headset and practitioner pair with a device code. Express for the APIs.
  • Svelte and Three.js WebXR client, Unity scene exporter and native Quest client, all on one session model.
  • Moved the platform from Fly.io to AWS ECS Fargate behind an ALB, with Cloudflare in front. Rolled out Auth0 login behind feature flags.
  • Patient input from Xbox Adaptive Controller, wheelchair joystick adapters and standard gamepads.
  • Joined as the company's first developer in 2021. Wrote the original application in C#, Unity and ASP.NET Core on the Reach Cloud codebase.

Stack TypeScript, Node, Colyseus, Express, Svelte, Three.js, WebXR, Unity, Meta Quest, AWS ECS Fargate, Auth0, Cloudflare, C# and ASP.NET Core.

Solla Code, a fork of T3 Code for running several AI coding agents at once

I run several coding agents at once and the terminal was a bad way to do it. Solla Code is my fork of T3 Code, extended into a desktop, web and mobile app. It runs many agents and providers side by side. It adds MCP tools, scheduled tasks, approval gating, and a browser the agents can drive. Upstream T3 Code is the editor and chat client. What I added is the orchestrator, the scheduler, the approval gates and the shared browser. I have put 850+ commits into it since July 2026, and it ships nightly prereleases and tagged stable releases.

  • Extended the upstream Electron, web and Expo mobile clients with an orchestrator and a persistence layer. All three share realtime state.
  • Orchestration across Claude, Codex and Gemini, with durable task scheduling, delegated work, approval gates and usage guards.
  • Browser tabs shared between the agents and the person. A human can take over a login or a form mid-task.
  • This is also how I work now. I write the specs, the data model and the acceptance tests. I direct the agents and review every diff. Every change runs through the test suites and CI before release.

Stack TypeScript, Electron, React, Node.js, Expo, MCP, Claude, Codex, Gemini, WebSockets.
